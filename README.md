Sobre

Este foi o meu primeiro projeto implementando um sistema CRUD (Criar, Ler, Atualizar e Deletar), que me ajudou a entender e aplicar os conceitos fundamentais por trás da manipulação de dados. O projeto consiste em um cadastro de pessoas, onde é possível registrar informações como nome, e-mail e telefone.

O principal objetivo desse projeto foi aplicar a lógica CRUD de forma simples e eficaz, permitindo que os dados possam ser adicionados, visualizados, editados e deletados. Apesar de ser um projeto inicial, foi um grande desafio que me proporcionou uma boa base sobre como gerenciar dados e implementar funcionalidades essenciais em sistemas web.
